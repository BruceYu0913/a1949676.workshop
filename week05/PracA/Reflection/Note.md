Task 3

The syntax differences between Lists and Arrays is that array uses string[] and Length, while a List uses List<string>, Count, and methods such as Add(), Remove(), Insert(), and AddRange().

Arrays are simple and efficient for fixed-size data, while Lists are more flexible but may use extra memory when resizing or moving elements.

I would use an array when the number of values is fixed, and a List when values need to be added, removed, or searched while the program runs.
